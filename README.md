# ניהול משימות וזמנים לעסק בניית אתרים

אפליקציית ווב לניהול העבודה בסטודיו בניית אתרים: מה צריך לעשות לכל לקוח, וכמה זמן באמת לקח כל פרויקט.

האפליקציה עובדת בדפדפן בלבד — אין שרת, אין הרשמה, והנתונים נשמרים מקומית ב-`localStorage` של הדפדפן.

---

## מה יש באפליקציה

### לקוחות
כרטיס לכל לקוח עם פרטי קשר, תעריף שעתי מוסכם והערות. בכרטיס הלקוח רואים את כל הפרויקטים שלו,
כמה שעות הושקעו בו, כמה הכנסות הוא הכניס ומה יצא **₪ לשעה בפועל** מולו.

### פרויקטים
כל אתר שבונים הוא פרויקט: מחיר מוסכם, הערכת שעות, תאריך התחלה ותאריך יעד, וסטטוס
(ליד / בעבודה / מושהה / ממתין ללקוח / הושלם). תאריך הסיום נרשם אוטומטית כשהסטטוס עובר ל"הושלם",
וזה מה שמאפשר למדוד את משך הפרויקט האמיתי.

### משימות ותבניות
המשימות מסודרות לפי שלבי העבודה — אפיון, עיצוב, פיתוח, לפני עלייה, עלייה לאוויר, מסירה.

במקום לכתוב מחדש את אותה רשימה לכל לקוח, בוחרים **תבנית** בפתיחת הפרויקט וכל המשימות נוצרות אוטומטית.
מגיעות ארבע תבניות מובנות:

| תבנית | משימות | למי זה מתאים |
|---|---|---|
| אתר תדמית מלא | 28 | אתר תדמית של 5-8 עמודים, מאפיון ועד מסירה |
| דף נחיתה | 12 | פרויקט קצר עם טופס והטמעת פיקסלים |
| חנות אונליין | 14 | קטלוג, סליקה, משלוחים ובדיקות רכישה |
| תחזוקה חודשית | 6 | ריטיינר חוזר ללקוח קיים |

אפשר לערוך תבניות, ליצור חדשות, ולשמור רשימת משימות של פרויקט קיים כתבנית לשימוש חוזר.

### מעקב זמנים
לוחצים ▶ ליד משימה והטיימר מתחיל לרוץ בראש המסך עד שעוצרים אותו. טיימר אחד פעיל בכל רגע —
הפעלת טיימר חדש עוצרת את הקודם אוטומטית. אפשר גם להזין זמן ידנית בדיעבד, ולסמן רישום כ"לא לחיוב".

### דוחות
זה החלק שעונה על "כמה זמן לקח כל פרויקט":

- **טבלת פרויקטים** — ימי לוח, שעות בפועל, מול ההערכה, הסטייה בשעות, ו-₪ לשעה בפועל
- **דיוק ההערכות** — כמה אחוז מהזמן שהערכת אתה באמת משקיע, עם המלצה מעשית לתמחור הבא
- **שעות לפי לקוח** — מי צורך הכי הרבה זמן
- **לאן הולך הזמן** — פילוח לפי שלב בתהליך (כמה באמת יורד על עיצוב מול פיתוח)
- **שעות לפי חודש**
- ייצוא ל-CSV (נפתח נכון באקסל בעברית)

## הפעלה

```bash
npm install
npm run dev      # סביבת פיתוח בכתובת http://localhost:5173
```

לבנייה לפרודקשן:

```bash
npm run build    # התוצר נכתב לתיקיית dist/
npm run preview  # תצוגה מקומית של הבנייה
```

תיקיית `dist/` היא אתר סטטי — אפשר להעלות אותה לכל אחסון סטטי (Netlify, Vercel, GitHub Pages,
או פשוט תיקייה בשרת). `base` מוגדר כ-`./` כך שהיא עובדת גם מתת-תיקייה.

## איך מתחילים לעבוד

1. **הגדרות** → קובעים שם עסק ותעריף שעתי ברירת מחדל. זה תעריף היעד שמולו נמדדת הרווחיות.
2. **לקוחות** → מוסיפים לקוח. אם סיכמתם איתו תעריף אחר, מזינים אותו בכרטיס הלקוח.
3. **פרויקטים** → פותחים פרויקט, מזינים מחיר ותאריך יעד, ובוחרים תבנית משימות.
4. **עבודה שוטפת** → מסך "משימות" מרכז את כל מה שפתוח בכל הלקוחות. לוחצים ▶ ומתחילים.
5. **דוחות** → אחרי כמה פרויקטים רואים אם התמחור נכון, ומתקנים את ההערכות לפרויקט הבא.

רוצים להתרשם לפני שמזינים נתונים אמיתיים? **הגדרות → טעינת נתוני הדגמה** ממלא את המערכת
בשלושה לקוחות וארבעה פרויקטים בשלבים שונים.

## על הנתונים

הנתונים נשמרים ב-`localStorage` של הדפדפן בלבד ולא נשלחים לשום שרת. משמעות הדבר:

- הנתונים זמינים רק בדפדפן ובמחשב שבהם הוזנו
- ניקוי היסטוריית הדפדפן או מחיקת נתוני אתרים ימחקו אותם
- **מומלץ לייצא גיבוי מדי פעם** — הגדרות → ייצוא גיבוי (קובץ JSON), ואפשר לייבא אותו בחזרה
  או במחשב אחר

## מבנה הפרויקט

```
src/
├── types.ts              מודל הנתונים (לקוח, פרויקט, משימה, רישום זמן, תבנית)
├── store.tsx             הסטייט המרכזי + כל הפעולות + שמירה אוטומטית
├── routes.ts             ניתוב מבוסס hash
├── lib/
│   ├── storage.ts        טעינה/שמירה, ייצוא-ייבוא גיבוי, ייצוא CSV
│   ├── selectors.ts      כל החישובים — שעות, התקדמות, רווחיות, פילוחים
│   └── utils.ts          פירמוט תאריכים, זמנים וכסף
├── data/
│   ├── templates.ts      התבניות המובנות
│   └── demo.ts           מחולל נתוני ההדגמה
├── components/           רכיבי UI משותפים, מודאלים, פס הטיימר
└── pages/                מסכי האפליקציה
```

בנוי ב-React 18 + TypeScript + Vite, ללא ספריות UI חיצוניות. הממשק בעברית ובכיוון RTL,
עם תמיכה אוטומטית במצב כהה לפי הגדרות מערכת ההפעלה.
